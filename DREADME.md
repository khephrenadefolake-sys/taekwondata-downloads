# TaeKwonData

Application Windows de gestion de clubs de taekwondo.

## Téléchargement

La version officielle de l'application sera disponible dans la section **Releases** de ce dépôt.

## Installation

1. Télécharge l'archive ZIP de la version souhaitée.
2. Extrais tout son contenu dans un dossier.
3. Lance `taekwondata.exe`.

Une connexion Internet est nécessaire pour les fonctionnalités qui utilisent Firebase.
